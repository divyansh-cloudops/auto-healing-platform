# Auto-Healing Platform

A Docker-based application monitoring and auto-recovery project built with Spring Boot.

## Features
- Spring Boot health endpoint
- Docker container monitoring and auto-healing
- Prometheus metrics and Grafana dashboards
- Email alerts
- AWS EC2 deployment
- Web monitoring dashboard

## Tech Stack
Java 21, Spring Boot, Docker, Prometheus, Grafana, AWS EC2, PowerShell
